# Improvements 05-09: Member Targeting & Event Charging

This folder contains user stories for two major feature enhancements requested on January 5, 2025.

## Features Included

### 1. Member Type Targeting in Communications (`/member-targeting/`)
Enable admins to send communications to specific member types rather than all members.

### 2. Event Charging with Payment Links (`/event-charging/`)
Allow clubs to create paid events with online payment and registration capabilities.

### 3. Targeted Event Invitations (`/targeted-invitations/`)
Send event invitations to specific member types based on relevance.

These features build upon existing GatherGrove infrastructure:
- Existing member types system
- Current payment processing (same as dues)
- Established communication channels
- Event management system
